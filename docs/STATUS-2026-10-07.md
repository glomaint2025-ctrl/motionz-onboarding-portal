## Bugs found by the browser test and fixed

2. Wrong file types and oversized files were only refused at Submit; now refused when picked.
3. No way to disconnect a client from GoHighLevel once connected.
4. A deleted staff member's open tab kept showing the app instead of the sign-in page.
5. An admin was told to "ask a Motionz admin" to change their email.
