# Phase 6: Client Portal — Onboarding and Setup

The Onboarding / Setup module organizes client configuration into five confirmed setup steps with transparent progress tracking.

## 1. Quick Access Links

At the top of the Onboarding / Setup page, clients have access to quick links:
- Communication Access / Slack: Direct access to the Motionz Slack workspace.
- Onboarding Forms: Access to the embedded GoHighLevel Onboarding Form.
- Skool Community: Access to the Motionz Skool training and community hub.
- A2P Verification Forms: Direct link to carrier A2P compliance submission form.

## 3. Card Information Architecture

Each setup card contains:
- Step Name: The name of the operational setup milestone.
- Owner: WE HANDLE (Motionz internal work) or YOUR ACTION (Client input needed).
- Status Badge: Not Started, In Progress, or Done.
- What it is: Clear description of the milestone.
- Right now: Current live operational status.
- We need from you (if applicable): Clear statement of needed information or access.
- Unlocks: Description of business capabilities enabled by completing the step.

## 4. Onboarding Information Collection

The client completes onboarding information through the embedded GoHighLevel Onboarding Form:
- Embedded URL: `https://api.leadconnectorhq.com/widget/form/wyM27h1ZCiwGoyXE03oC?notrack=true`
- Clean iframe presentation without extraneous redirects.
- No invented or unconfirmed question fields in documentation.

## 5. Administrative Controls

CSM and Admin users can edit card titles, descriptions, unlock text, and status values directly from their workspaces.
Progress percentage is dynamically calculated from the status of these 5 steps.
